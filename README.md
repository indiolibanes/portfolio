# Portfolio

Microsite pessoal de Kauê Alencar em Astro.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Saída estática: `dist/`.

## Cloudflare Pages

- Framework preset: **Astro**
- Build command: `npm run build`
- Build output directory: `dist`
- Node: `22.12+`

O projeto foi preparado para ser público por URL, mas não indexável por buscadores (`robots.txt`, meta robots e `X-Robots-Tag`).

## Separação de identidade

Este repositório não deve conter referências ao projeto autoral pseudônimo, ao domínio correspondente ou ao repositório público que o hospeda. O e-mail público também está vazio por padrão pelo mesmo motivo.
