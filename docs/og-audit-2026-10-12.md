## Arte correta — já criada no commit original

- `assets/og-portfolio.png`: fonte rasterizada 1200 × 630, com Sophia do laboratório, óculos redondos, reflexos e dedo/pata erguida; fundo azul-noite com estrelas e legenda “não ironicamente”.
- `public/og-portfolio-animated.gif`: GIF opcional 800 × 420 (~605 KiB); **não** referenciado pelas tags OG/Twitter porque o JPG é mais previsível como thumbnail.
- `scripts/build-og-card.py`: regeneração autoral offline; requer Pillow, NumPy, SciPy e OpenCV. É ferramenta de edição e **não** requisito para o build do site.
- `scripts/generate-og.mjs`: converte o PNG versionado para `public/og-portfolio.jpg` via Sharp antes de `astro build`; não lê mais o SVG antigo.
- `src/config.ts`: `ogImage: '/og-portfolio.jpg?v=20261012b'`. A mudança da query evita alguns caches antigos, mas não assegura a atualização imediata em cada plataforma.

## Melhorias implementadas aqui

1. `og:site_name` adicionado ao head.
2. `SITE.ogImageAlt` centraliza a descrição da imagem; `og:image:alt` e `twitter:image:alt` reutilizam o mesmo valor, específico do meme.
3. `scripts/verify-og.mjs` valida, sem instalação adicional, assinatura e dimensões do PNG fonte e GIF, URL absoluta HTTPS com versão, alt, ligação das tags, uso exclusivo do JPG e conversão via Sharp.
4. `node scripts/verify-og.mjs --dist`, executado no final de `npm run build`, verifica o JPEG 1200 × 630 realmente produzido e as tags, URLs canônicas, títulos, descrições, idiomas e alt das páginas home e Sophia. Suporta barra final opcional em `/sophia`.
5. `npm run check:og` disponibiliza a verificação **pré-build**, sem depender de `dist/`.

## Procedimento de QA para o merge e o deploy

```sh
npm install
npm run check:og
npm run check:ux
npm run build
```

O build deve terminar com `OG index.html: PASS`, `OG sophia/index.html: PASS`, `OG dist: PASS`. Abrir o JPG gerado e inspecionar hierarquia, legibilidade do meme e corte em 320–400 px.

Depois do deploy, verificar por HTTP:

- `https://kaue.pages.dev/` e `https://kaue.pages.dev/sophia/`: `og:image` absoluto com `?v=20261012b`, canonical correto, alt descritivo e `twitter:card=summary_large_image`.
- `https://kaue.pages.dev/og-portfolio.jpg?v=20261012b`: 200, `image/jpeg`, 1200 × 630, imagem nova.
- `https://kaue.pages.dev/og-portfolio-animated.gif`: 200, `image/gif`, GIF preservado, mas fora das tags.
- Compartilhar URL em apps e forçar atualização por ferramenta oficial, quando disponível. Não prometer invalidação automática do cache.
