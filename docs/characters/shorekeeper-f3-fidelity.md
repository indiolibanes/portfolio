## Implemented in FIDELIDADE only

- **Rest:** the former camera fit follows a stage/world azimuth, which can disagree with the anatomical front. A new read-only rig-camera adapter fits the anatomical front, subtle 15° three-quarter or profile. It changes the camera only. Without the three source idles, the claim that their pose itself is wrong remains unproven; no Root offset or rest quaternion is changed.
- **Liberation:** F2's late absorption and giant-wing opening are authorial, not established by the reference cutscene. FID replaces that giant-wing slot with a procedural radial rupture, bounded bright core, fast wavefront, divergent fragments and canopy/ground response. The existing mesh/material/buffer slots are reused. Timing and strength are explicitly a reconstruction candidate, not VFX_MATCHED. No invented compression/implosion phase is asserted.
- **Small butterfly and camera:** F2 trigger shader, silhouette, trajectory, scale, transparency and uniforms remain unchanged. F2's hard camera cuts at reference 3.80/4.20 s are retained with the existing proportional mapping. Neither body timing nor original curves were retimed.
- **Independent actions:** a catalogue describes preconditions, entry, execution, recovery, interruption, disposal, sources and evidence per action. Unmatched actions stay blocked. Explicit source inspection reuses the body lease and source-review director; Burst inspection retains F1 BODY Root ownership. It is source QA, not a certified canonical action player.
- **Provenance:** source identity is bound to the actual AnimationClip object and immutable File, not its name. ART load records cheap receipts. First explicit FID admission rechecks the full source SHA, parses animation data without textures/GPU and compares live curves against independently parsed source signatures. Same-name replacements, modified tracks, stale asynchronous admission and absent sources are rejected before replacing the current owner. The source File is retained until verification or collection; browser memory impact remains unmeasured.
- **Field state:** the new independent contract requires explicit validated End Loop / Intro / Discernment / expiration events. Replay sequence numbers remain rejected after closure. It does not infer Inner/Supernal or canonical field termination from the presentation timeline.

ARTÍSTICO remains the existing G11.3. Music gating, original clips, facial R5/R6, model/skin, Access/R2 and the duet are not redesigned. The new source-inspection controls exist only in the explicitly selected FID laboratory.

## Performance evidence

The Liberation layer keeps its six existing mesh/material slots and 224-mote buffer. There is no new scene, renderer, render target, texture, independent simulation, bloom pass or RAF in production. Additional draw calls and shader cost have **not** been measured in WebGL. Reuse of slots is a structural budget, not proof of equal GPU cost.

One Node run measured cheap source receipt registration at 0.129/0.130/0.142 ms and first explicit FID verification at 278.7/247.7/164.9 ms (basic/advanced/burst). These are one-time CPU observations, not browser load timings, FPS, before/after gains or mobile measurements. Subsequent verification uses cached expected signatures, never a per-frame hash.
